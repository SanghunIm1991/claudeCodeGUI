# claudeCodeGUI

Claude Codeとバイブコーディングによる「ウォーターフォール開発」および「自律ループモード」を支援するローカル実行のWebアプリ。

## 目的

- 事前に登録したプロンプトテンプレートを使い、Issueの入力から各工程（要件定義／設計／実装／テスト等）の実行指示を出す
- 各工程の成果物を閲覧・修正できる
- 自律ループモードでの継続実行にも対応する

## 技術スタック（決定事項）

- **バックエンド**: ASP.NET Core (C#) — `dotnet` SDKは導入済み（8.0.408 / 9.0.314）
- **フロントエンド**: 素のHTML/CSS/JavaScript（`wwwroot`配下の静的ファイル、ビルドステップなし）
  - Node.js/npmが開発機に未導入のため、ビルド不要な構成を採用
- **実行エンジン**: `claude` CLI（`C:\Users\21452\.local\bin\claude.exe`）をheadlessモード（`-p` 等）でサブプロセス起動し、工程ごとの実行・自律ループを制御する

## 現在の状態

最小構成のプロトタイプまで実装・動作確認済み。

- Issue／プロンプトテンプレートをファイルベース(JSON, `src/ClaudeCodeGui/runtime-data/`)で管理
- Issueを選び、工程（要件定義／設計／実装／テスト／デプロイ）ごとのテンプレートを選んで実行すると、
  `claude` CLIをheadlessモード（`-p --output-format stream-json`）でサブプロセス起動し、
  実行ログをSSEでリアルタイム表示
- 成果物は対象プロジェクトのリポジトリ内にそのまま生成され、GUI上のブラウザから閲覧・編集可能

### データモデル

- `Issue`: タイトル・説明・対象プロジェクトパス・現在の工程・ステータス
- `PromptTemplate`: 工程ごとのプロンプト（`{{issue.title}}`等のプレースホルダ対応）
- `Run`: 実行履歴（状態・終了コード・結果サマリ）
